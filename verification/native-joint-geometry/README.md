# Same-source native joint geometry and weighted Haar limits

This addition consists of the 41 modules in `modules.json`. A focused Lake
build succeeded (6,722 jobs), followed by the ordinary, non-overlay command
`lake env lean --trust=0 verification/native-joint-geometry/CheckAllDeclarations.lean`.
The audit traversed each module's actual environment declarations, including
generated auxiliaries: all 230 use only `propext`, `Classical.choice`, and
`Quot.sound`, or subsets thereof. Source hashes are recorded alongside the
build and axiom logs. The original 3,059-file snapshot still verifies.

  `affineShear_native_joint_face_lifts_in_coordinates` allows those coordinates

## Boundary

These are genuine geometric and limit statements, not a proof of the full
uniform Alignment principle. The concrete Alignment slot transformations
still have to be fed through the face-lift interface, interpreted along the
fixed finite recurrence routes and actual observables, and combined with
the paper's closed/open threshold comparisons and conditional pivot mass
iteration. The constants must retain their prescribed independence from
thresholds and model complexity. The higher-order finite-model linear
inverse theorem also remains open. Neither the canonical root imports nor
the original verification manifest is changed by this addition.
